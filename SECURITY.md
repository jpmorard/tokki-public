# Security policy

## Supported versions

Only the latest public release record and its corresponding authorized wheel
are supported. At publication time, that version is `1.0.53`.

## Report a vulnerability

Use GitHub **Private Vulnerability Reporting** for this repository. Do not open
a public issue for a security report. If the private-reporting control is not
available in GitHub's Security tab, do not disclose the vulnerability publicly;
ask the repository owner to enable it first.

Do not include API keys, access tokens, credentials, prompts, chat content, raw
command output, private repository contents, customer data, absolute paths, or
unredacted support bundles. A minimal report should include the affected Tokki
version, platform, a safe reproduction outline, expected/actual behavior, and
impact assessment.

## Response process

The maintainer targets acknowledgement within five business days. Triage,
remediation, validation, and coordinated disclosure are handled privately. A
public advisory is published only after a fix or mitigation is available, or
when coordinated disclosure requires it.

This repository exposes release metadata, not implementation source. The
absence of a public advisory does not constitute a security guarantee.
