# Tokki · From one request to a working app

Try the app built through Tokki's autonomous agent workflow with AGILAB.
No account or AI provider subscription is needed to explore the completed app.

This static Tokki Space embeds the verified interactive app from the existing
[AGILAB Space](https://huggingface.co/spaces/jpmorard/agilab). The app's model,
notebook and interface checks run there; this page runs no agent provider.

[Build from your own notebook](https://github.com/ThalesGroup/agilab#build-from-your-own-notebook)
with your own local Tokki installation and provider. Nothing is submitted
automatically when the local builder offers an optional completion receipt.

[Tokki public overview and releases](https://github.com/jpmorard/tokki-public)
· [AGILAB](https://github.com/ThalesGroup/agilab)

Deploy this directory's `index.html`, `README.md` and `LICENSE` to the static
`jpmorard/tokki` Space. It needs no secrets or compute upgrade.
