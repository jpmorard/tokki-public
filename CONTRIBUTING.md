# Contributing

Tokki implementation is proprietary. Contributions to this repository are
limited to public documentation, release-evidence metadata, accessibility of
the public diagrams, and safe installation guidance.

Never include prompts, raw logs, credentials, customer material, private source
paths, or private wheel contents in an issue or pull request. Use public issues
for documentation and package-metadata defects; use the private security flow
in [SECURITY.md](SECURITY.md) for vulnerabilities.

Public release claims must be backed by the matching files in `releases/`.
Do not add a wheel, source archive, or private build script to this repository.
